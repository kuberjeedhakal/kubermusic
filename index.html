YouTube Data API v3 Key (अनलाइन युट्युब खोजको लागि)

अनलाइन हुँदा गानाको नाम लेखेर सीधै युट्युबमा खोज्नको लागि आफ्नो निःशुल्क Google Cloud YouTube Data API v3 Key सेभ गर्नुहोस्।

API Key लिन: Google Cloud Console → APIs & Services → YouTube Data API v3 Enable → Credentials → Create API Key।

एन्ड्रोइड र Brave मोबाइलमा स्क्रिन लक प्ले सेटअप

  1. Brave Background Play: Brave Menu (⋮) → Settings → Media → Background play ON गर्नुहोस् (यसो गर्दा अनलाइन युट्युब पनि स्क्रिन लकमा बज्छ)।
  2. ब्याट्री अप्टिमाइजेसन: Android Settings → Apps → Brave → Battery → Unrestricted राख्नुहोस्, ताकि स्क्रिन लक हुँदा अडियो नरोकियोस्।
  3. अफलाइन भिडियो स्क्रिन लकमा बजाउन: भिडियो प्ले भएपछि "स्क्रिन-लक अडियो मोड" थिच्नुहोस् — त्यसपछि स्क्रिन लक गर्दा पनि लक-स्क्रिन कन्ट्रोलसहित आवाज निरन्तर बज्छ।
  4. एप जस्तै इन्स्टल गर्न: Brave Menu (⋮) → Add to Home screen / Install app थिच्नुहोस्।

युट्युब नियम र अफलाइन भल्ट बारे स्पष्ट जानकारी

YouTube को आधिकारिक Terms of Service अनुसार YouTube सर्भरबाट भिडियो/अडियो सीधै डाउनलोड वा स्क्र्याप गर्न पाइँदैन (YouTube Premium बाहेक)। त्यसैले यो एपले अनलाइनमा आधिकारिक YouTube Player प्रयोग गर्छ र तपाईँको डिभाइसमा भएका वा डाउनलोड गरिएका अडियो/भिडियो फाइलहरूलाई IndexedDB भल्टमा सुरक्षित राखी अफलाइन खोज, प्लेब्याक र रिट्राइभ सुविधा दिन्छ।
